# ECMS MVP Scope

## Purpose

Deliver a usable project-control system for construction teams without attempting a full construction ERP in the first release.

## Included in the MVP

### 1. Executive Dashboard

- Executive summary
- Project status
- Financial summary
- Notifications

### 2. Project Management

- Project register
- Project profile
- Project team

### 3. Planning & Progress

- Activities
- Baseline schedule
- Daily progress
- Planned vs. actual

### 4. Procurement & Materials

- Material register
- Material request
- Purchase order
- Goods receipt
- Stock balance
- Material issue

### 5. Cost Control

- Budget
- Actual cost
- Commitments
- Budget vs. actual

### 6. Document Management

- Drawing register
- Revision control
- RFIs
- Document search

### 7. System Administration

- Users
- Roles
- Audit trail

## MVP User Roles

- Project Manager
- Site Supervisor
- Storekeeper

## Deferred to Phase 2

- Contract administration: BOQ revisions, variations, claims, EOT, IPC, retention, and advance payment.
- Cash flow management.
- Equipment management.
- QA/QC and HSE management.
- Supplier evaluation and supplier performance.
- Advanced reports, business intelligence, and duplicate specialist dashboards.
- Multi-branch organization configuration, email/SMS, backup and restore, and advanced workflow configuration.

## Navigation Principle

The MVP exposes seven modules only: Dashboard, Projects, Planning, Procurement & Materials, Cost, Documents, and Administration. Each screen should lead with a task such as create, submit, review, approve, search, export, or open.
